# Swemessage 
Новый мессенджер 

*Встречайте новый, чистый, быстрый и безопасный Swemessage!*

# Что добавим?
В 2027 мы добавим кастомные темы, события, форум-группы и т.д.

## Как запустить?
1. Открой `index.html` в браузере
2. Или заходи на https://user3948283838.github.io/Swemessage/

## Возможности
- 💬 Текстовые сообщения
- 📞 Аудио-звонки (WebRTC)
- 👥 Поиск пользователей по ID
- 🎨 Тёмная тема
